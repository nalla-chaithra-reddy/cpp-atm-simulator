# C++ ATM Simulator

A beginner-friendly ATM Simulator built using C++ fundamentals.

## Features

* Check current balance
* Deposit money
* Withdraw money
* Validate deposit and withdrawal amounts
* Handle invalid menu choices
* Exit the ATM safely

## Concepts Used

* Variables and data types
* Input and output (`cin` and `cout`)
* Conditional statements (`if`, `else if`, `else`)
* Infinite loops
* `break` statement
* Arithmetic operators
* Basic input validation

## How It Works

The program starts with an initial balance of ₹10,000.

The user can choose from four options:

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

The program continues running until the user selects the Exit option.
